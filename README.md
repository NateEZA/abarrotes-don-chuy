# Abarrotes Don Chuy — E-Commerce Flask

Sistema de comercio electrónico para una tienda de abarrotes, desarrollado con Flask y control de acceso basado en roles (RBAC).

## Requisitos previos

- Python 3.8+
- Virtualenv (`venv`)
